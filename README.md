# obs-now-playing-windows
«Сейчас играет» — нативный плагин для OBS Studio на Windows, который показывает название музыки или видео из Spotify, YouTube, браузера и других приложений. Поддерживает выбор источника, шаблоны текста, стили, JSON-пресеты, бегущую строку, плавную анимацию и скрытие при паузе. Работает без отдельного EXE и API-ключей.
