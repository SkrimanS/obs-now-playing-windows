# Установка плагина «Сейчас играет» для OBS

1. Полностью закройте OBS Studio, включая значок OBS в системном трее.

2. Скачайте и распакуйте архив `obs-now-playing-<версия>-windows-x64.zip` со страницы Releases.

3. Откройте в Проводнике папку:

   `C:\ProgramData\obs-studio\plugins`

   Если папки `plugins` нет — создайте её.

4. Скопируйте распакованную папку `obs-now-playing` целиком в папку `plugins`.

5. Проверьте, что файл плагина находится по адресу:

   `C:\ProgramData\obs-studio\plugins\obs-now-playing\bin\64bit\obs-now-playing.dll`

   Не должно быть лишнего вложения `obs-now-playing\obs-now-playing`.

6. Запустите OBS Studio.

7. В блоке «Источники» нажмите `+` и выберите **«Сейчас играет»**.

8. Откройте свойства добавленного источника, выберите нужное приложение или окно и запустите музыку либо видео.

Отдельное приложение запускать не нужно — плагин работает внутри OBS Studio.
