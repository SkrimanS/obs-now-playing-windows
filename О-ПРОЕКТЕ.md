# «Сейчас играет» для OBS Studio

Нативный плагин для OBS Studio, который показывает название воспроизводимой композиции или видео. Работает в Windows 10 и Windows 11 без отдельного приложения и API-ключей.

Плагин получает данные через Windows SMTC или заголовок выбранного окна. Поддерживаются Spotify, браузеры, YouTube и другие приложения, которые передают медиаданные в Windows.

Основные возможности:

- выбор конкретного приложения или окна;
- шаблон текста `{artist} — {title}`;
- автоматическое скрытие при паузе;
- плавное появление и исчезновение;
- автоматическая бегущая строка для длинного текста;
- готовые стили и собственные JSON-пресеты;
- русская и английская локализации;
- отсутствие отдельного фонового EXE-файла.

Текущая версия поддерживает только 64-битную OBS Studio в Windows.

Инструкция для пользователей находится в [README.md](README.md), а руководство по собственным стилям — в [СОЗДАНИЕ-ПРЕСЕТОВ.md](СОЗДАНИЕ-ПРЕСЕТОВ.md).
