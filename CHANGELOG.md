# История изменений

## 0.6.0

- Добавлена автоматическая бегущая строка для текста, который не помещается в выбранную область.
- Добавлена настройка скорости бегущей строки.
- Скорость поддерживается в собственных JSON-пресетах.
- Короткий текст остаётся неподвижным и не перерисовывается каждый кадр.
- Частота анимации автоматически снижается для очень больших областей, а у скрытых источников анимация останавливается.

## 0.5.1

- Подсказка для JSON-пресетов сделана постоянно видимой вместо значка вопроса.

## 0.5.0

- Добавлены безопасные собственные стили в формате JSON.
- Добавлена русская инструкция и готовый запрос для создания пресетов через GPT.

## 0.4.2

- Исправлено восстановление выбранной SMTC-сессии после перезапуска Spotify или браузера.

## 0.4.1

- Улучшены плавное появление, прозрачность, стабильность и проверка настроек.
- Добавлены готовые стили оформления и русская локализация.
